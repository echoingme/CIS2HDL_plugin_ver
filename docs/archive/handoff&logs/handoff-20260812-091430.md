## 3. 转换管线（当前态）

```
Stage 1:   DSN Parse         → DesignIR（20 DSN 页）
Stage 2:   Catalog Load      → ComponentCatalog（CrossRef CSV）
Stage 2.5: CrossRef→DesignIR → 1219 实例（914 元件 + 305 电源符号，含坐标/值）
Stage 3:   HDL Scan          → ComponentDB（hdl_lib 扫描）
Stage 4:   Match Pipeline    → Exact→Fuzzy→Feature→Value→Fallback + power_ic（Phase XIV）
Stage 4.5: D3 人工匹配注入   → manual_matches.yaml 覆盖（Phase XIV）
```

## 12. 关键设计决策（完整记录）

1. **镜像归一化而非 M 行**：DEHDL MY/MX 语法未验证（04p4 无参考）；引脚坐标精确变换保电气，渲染用最接近旋转近似（chirality 无法纯旋转表达），approx 标注人工复核
2. **镜像在前、旋转在后**：EDIF 2.0.0 标准（MXR90 = MX∘R90）；旧实现顺序相反但无组合路径，无回归
3. **电源符号 LASTPIN 与 Pass1 同源**：`rotate_point(0,±50,mirror)`，禁止硬编码 y±50（Phase XVI bug 教训）
4. **审计基于 DesignConnectivity 模型**：raw EDIF pin_connections 未注入 → 孤立检测 100% 误报（架构师数据源铁律）
5. **网名不一致只报告不自动合并**：跨页改名有电气风险；`ioport.manual_names` 人工裁决
6. **LASTPIN 内联各 FORCEADD 块**：集中文件尾会挂到 IOPORT 被删（SPCOCN-543）
7. **吸网格在坐标源头**：LASTPIN 与 WIRE 端点同步移动，保持精确重合（DEHDL 坐标重合=连接硬约束）
8. **aesthetic 自动启用美观布线**：用户"没区别"根因（mode=detour + ioport/gnd 分布）
9. **占位符号替代错误 fallback**：CH347 教训——错误符号比无符号更误导；PLACEHOLDER 标注
10. **所有新功能独立模块+配置开关默认关**：用户强制，随时增删功能、可回退
11. **wire_layout 保持几何合成单一职责**：布线策略抽象到 Router 层
12. **GND 每芯片分布**：电气不变（同网 SIG_NAME），只增符号分布到各芯片
13. **页内网用网络名、跨页网用 IOPORT**：符合硬件设计规范 §3.2"同层设计用网络名不用 port"
14. **占位符号默认开**：用户明确要求后端默认生效（placeholder.enabled=true）
15. **默认出诊断报告**：report.always_write=true，只读不影响 CSA
