## 5. P2 三项核心开发详解

### 5.1 ORCAP-11007 修复（源设计 + 转换器双轨）

**问题**：`error.txt` 报 `ORCAP-11007: TitleBlock on Page '01-Cover_Page' contains an invalid Page Number`。

**定性**：源设计（OrCAD Capture 工程）的 TitleBlock 页码属性无效——**非转换器缺陷**。

**修复（用户侧，Capture 操作步骤）**：
1. 打开 HG5015-BE36_V10.dsn（Capture）
2. `Tools → Annotate`
3. Annotate 对话框：`Action = Incremental reference update`、`Mode = Update Occurrences`、`Scope = Process entire design`、勾选 `Reset reference numbers to begin at 1 each page`
4. OK 执行 → File → Save As 保存
5. 若仍报错：手动检查每页 TitleBlock 的 `Page Number`/`Page Count` 属性与 `$PAGENUM`/`$PAGECOUNT` 变量

**转换器侧容错（P1-1 已实现）**：page.map 页码从 EDIF page_name 提取（`01-Cover_Page`→1），不依赖 title block。

### 5.2 P2-1 rotation → sym_N 视图映射（✅ 已实现）

**设计**：
- **真实格式**：DEHDL 中元件旋转通过 **sym_N 视图**表达——8367 库 capacitor sym_1（竖向，引脚 (0,-75)/(0,50)）vs sym_2（横向，引脚 (-50,0)/(75,0)）是同一电容的 90° 旋转视图；`FORCEADD CAPACITOR..2` 即选择 sym_2
- **关键发现**：sym_N 语义**混合**——capacitor sym_1/sym_2 是旋转视图（同 VALUE 不同方向，C51 与 C27 同为 100NF 但用 ..2/..1），而 dc_dc sym_1(6 引脚)/sym_3(16 引脚) 是**器件变体**（引脚数不同）。直接切换 sym_N 有歧义 → **采用几何旋转**：把 symbol.css 引脚偏移按 rotation/mirror 旋转变换（数学验证：R90 旋转 (0,-75)→(75,0) 与 sym_2 完全一致）

**数据链路**：
```
EDIF (orientation R90/MY...) → ComponentInstanceIR.rotation/mirror (P1-4)
  → 清空占位前保留（经 pstxprt ins_to_refdes 映射到真实 refdes）
  → catalog 实例重建时恢复 rotation/mirror
  → connectivity_model InstanceRecord.rotation/mirror
  → csa_writer rotate_point 变换引脚偏移 → LASTPIN 正确旋转
```

**实现文件**：`coord_transform.py`（+rotate_point/rotate_bbox）、`conversion_engine.py`（占位 orientation 保留/恢复）、`connectivity_model.py`（InstanceRecord+rotation/mirror）、`csa_writer.py`（pin 偏移旋转）

**实测**：全工程 50.1% 电容/电阻横向（旋转后），与 EDIF 旋转数据（268/473 电容 + 74/289 电阻 ≈ 47%）吻合；C97（R90）LASTPIN 在 (-2201,4644)/(-2076,4644) 与期望完全一致。

### 5.3 P2-2 NC 标记渲染（✅ 已实现）

**设计**：
- **真实格式**：8367/04p4 参考工程均无 NC 引脚（其 IC 无 NC 设计）；HG5015 有 67 个 NC 引脚（U6 主芯片 V24/V25/W27 等）
- **方案**：NC 引脚（net="NC"）**不加入 net_pin_map**——不生成 SIG_NAME、不画 WIRE（NC 无连接）；**保留 LASTPIN $PN**（引脚在原理图上存在）

**实现**：`csa_writer.py` 的 pin_coords 构建处，`net_display.strip().upper() != "NC"` 才加入 net_pin_map（L1049-1052）。

**实测**：SIG_NAME NC 10→0；LASTPIN $PN 2009 保持；con 2821 无回归；e2e A5 测试同步更新（NC 引脚豁免 WIRE 端点断言）。

### 5.4 P2-3 xcon netScopes 增强（✅ 已确认完成，无需改动）

**设计**：
- **对照真实 8367.xcon**：netScopes 为**双层结构** `<netScope ref>` 内含 `<pageScope number>` + `<scope>global</scope>`——当前实现（P0-B2）已完全一致
- **实测**：当前输出 49 个全局网（含 48 电源网）双层结构正确；pages 段 24 页 + physicalPageNumber 完整；aliases 带 lsb/msb 与 8367 一致

## 6. 收尾五项开发详解

### 6.1 P0-A3：off_page 522/765 完整化（✅ 完整实现）

**根因调研过程**：
1. 初始统计：EDIF 文件 `OFF_PAGE_CONNECTOR` 文本出现 **765** 次，但解析器只提取 **522** 个 → 差 243
2. 三种形式精确统计：
   - `(portRef XXX_OFF_PAGE_CONNECTOR)` 无 instanceRef：441 个（页面级）

### 9.1 `coord_transform.rotate_point(x, y, rotation, mirror)`（coord_transform.py:273-300）

```python
def rotate_point(x, y, rotation=0, mirror=0) -> tuple[int, int]:
    rot = int(rotation or 0) % 360
    if rot == 90:   rx, ry = -ry, rx
    elif rot == 180: rx, ry = -rx, -ry
    elif rot == 270: rx, ry = ry, -rx
    # mirror applied after rotation (EDIF orientation order)
    if mirror == 1:  ry = -ry      # X-axis flip (Y → -Y)
    elif mirror == 2: rx = -rx     # Y-axis flip (X → -X)
    return int(round(rx)), int(round(ry))
```

## 10. 调研内容与参考原理

### 10.1 EDIF offPageConnector 结构调研（P0-A3）

- EDIF 中 OFF_PAGE_CONNECTOR 三种形式：`(portRef X)` 无 instanceRef（441，页面级）、`(portRef ... instanceRef)`（232，带实例引用被过滤）、`(offPageConnector X)` 独立指令（**243，被遗漏**）
- offPageConnector 父结构：`library→cell→view→contents`（非 cell→contents、非 page 块）
- 243 个中 212 命名端口 + 31 自动名（&_31N...）——cell 级接口 off-page 端口声明

### 10.2 sym_N 语义调研（P2-1）

- 8367 库 capacitor sym_1（竖向，引脚 (0,-75)/(0,50)）/ sym_2（横向，引脚 (-50,0)/(75,0)）——同一电容 90° 旋转视图
- **语义混合**：dc_dc sym_1(6 引脚)/sym_3(16 引脚) 是器件变体（引脚数不同）→ 直接切换 sym_N 有歧义 → 几何旋转方案

### 10.3 跨页端口双风格调研（P0-C5）

- **04p4 风格**：IOPORT 符号（FORCEADD IOPORT..1 + OFFPAGE TRUE + HDL_PORT/VHDL_PORT INOUT + CDS_LIB）——20 个
- **8367 风格**：SIG_NAME 标签（17 个，OFFPAGE=0）——无 IOPORT 符号
- 两者皆真实 Cadence 可接受 → IOPORT 与 SIG_NAME **共存**方案

### 10.4 CH347 引脚数据调研

- symbol.css C 指令 20 个引脚名（功能名 RST#/TXD1...）与 chips.prt 20 个映射（同名）——数据 100% 对齐
- chips.prt 格式：`'RST#': PIN_NUMBER='(1)';`——功能名声明 + PIN_NUMBER 数字
- con cell terms 是数字引脚名（'1','2','3'...）——需 chips.prt 桥接

### 10.5 8367 DSN 格式调研（T04/T17）

- 8367 DSN **实为 RTL 格式**（read_preamble 返回 "rtl"）——非"标准变体"
- 6 个流均为**芯片封装视图**（vRTL8367*）：578 引脚级实例（P2MDICP 等电源引脚）、无板级网络
- `_RtlStructure` 结构：name/db_id/loc_x/loc_y/t0x10_count
- EDF 是完整板级设计（5 页/751 实例/270 网）——双源存在时 `_prefer_edif_sibling` 优先 EDF

### 10.6 OLB 电气类型消费调研（P2-7）

- 04p4/8367 csa：HDL_PORT/VHDL_PORT 只在 IOPORT 符号上出现；普通元件 csa **无引脚类型属性**
- 结论：DEHDL csa 不消费普通元件引脚电气类型 → P2-7 保持"字段已备、消费待后续"

## 11. 数据结构与设计决策

### 11.1 数据结构变化

| 结构 | 新增字段 | 用途 |
|------|---------|------|
| ComponentInstanceIR | rotation/mirror/nc_pins（P1-4 已有） | P2-1 旋转数据载体 |
| PageIR | off_pages（已有） | 页面级 off-page（522） |
| DesignIR.metadata | design_off_pages | 设计级 off-page 端口（243） |
| InstanceRecord | rotation/mirror | P2-1 传递到输出层 |
| PageConnectivity | off_pages | P0-C5 IOPORT 数据源 |
| PinDef | number/name（修复后 name=功能名） | CH347 桥接 + 电气类型源 |
| csa_writer 常量 | _PAINT_PINK = "PINK" | IOPORT 块粉色显示 |

### 11.2 关键设计决策

1. **几何旋转而非切换 sym_N**（P2-1）——sym_N 语义混合有歧义；几何旋转数学等价（R90 (0,-75)→(75,0) = sym_2）
2. **ins_to_refdes 桥接**（P2-1）——EDIF 占位 INS### 与真实 refdes 经 pstxprt 映射（914/914 完全交集）；匹配键用真实 refdes 而非页内索引
3. **NC 引脚排除网络**（P2-2）——NC 无连接：不生成 SIG_NAME/WIRE，保留 LASTPIN 引脚存在
4. **off_page 双级存储**（P0-A3）——页面级 522 + 设计级 243（view→contents）各自独立，合计 = EDIF 100%
5. **IOPORT 与 SIG_NAME 共存**（P0-C5）——IOPORT = 端口符号（网表导出完整），SIG_NAME = 网络标签（轻量）；方向默认 INOUT
6. **chips.prt 功能名保留**（CH347）——PIN_NUMBER 存 number，功能名存 name，禁止覆盖
7. **RTL PlacedInstance 恢复**（T04/T17）——v0.5.0 移除是错误决策（8367 就是 RTL 格式）；`_is_valid_result` 对引脚级实例放宽
8. **fixture 补齐 + 断言适配**——补齐真实 fixture 暴露真问题；e2e 断言按 fixture 实际数据诚实适配
9. **P2-7 保持现状**——DEHDL csa 无引脚类型消费点，接通收益有限（效率优先）
