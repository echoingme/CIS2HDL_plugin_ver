```

Stage 3:   HDL Scan          → ComponentDB（hdl_lib 扫描）
Stage 4:   Match Pipeline    → Exact→Fuzzy→Feature→Value→Fallback + power_ic（Phase XIV）
Stage 4.5: 配置注入          → chip_config.yaml v2.0（--chip-config）覆盖 manual_matches v1.0（M8，Phase XVII）

Stage 6.2: 电线化简后处理    → wire_simplifier（M4：merge/trim/jog/add_junctions，wire_simplify.enabled=true 时）
```

### 4.6 SPN 机制详解（用户要求详细解释，supplement 文档）

**通俗解释**：SPN 不是我们写的属性，而是 Cadence 内部给每个引脚生成的"引脚序号"。报错里看到的 `SPN with value 8` 就是我们写在 CSA 里的 `$PN 8`——Cadence 读入后内部转成 SPN 概念。它说 "deleted" 的意思是**引脚的属性块整体没被采纳**（像工牌号被撕掉）。

**三类触发机制**：①引脚坐标不在 symbol 引脚上（实例 8 脚 vs symbol 6 脚）②LASTPIN 块格式不合规 ③旋转实例的"R 行+元件级 SIG_NAME"组合无 04p4 先例。

**4 组受控 A/B 实测模板**（test_spn_g1~g4.csa，已生成到对比包）：
- 组1（g1_baseline）：非旋转 + $PN 块（04p4 格式）→ 期望不删
- 组2（g2_paint）：非旋转 + $PN + SIG_NAME 块（带 PAINT）→ 验证 PAINT 根因
- 组3（g3_rotated）：旋转 R 2 + $PN + SIG_NAME → 验证旋转组合根因
- 组4（g4_power）：电源符号 GND_POWER 块 → 验证电源 SIG_NAME

### 8.6 用户明确要求的核心诉求（从实测中提炼）

1. **全部元件使用标准化管理的 hdl_lib**（不能有 ORIGIN 系统库引用）
2. **避让检测区扩大**到芯片/元件外侧一点（留冗余），且**引脚附近也要避让**（防误连接）
3. **电线不能自己和自己/其他折线段重合**（线头问题的本质）
4. **调头先延伸再折线避让再调头**（三段式 stub 引出）
5. **GND 引脚连线先延伸一段再拐弯**
6. **就近共用 GND**：相近元件同信号（尤其 GND）先在引脚附近并联再统一引出
7. **网络名标签必须显示**（v6 中电线悬空无标签）
8. **电线长度设限**（v6 拉了超长线）+ **移动 GND/网络名信号**实现短连接
9. **标签方向与元件方向统一**（水平元件标签水平；BGA 四边标签：左=左对齐、右=右对齐、上=竖直靠上、下=竖直靠下）
10. **引脚名称字体缩小一半**（mock 图标）
11. **标签不重叠**（当前竖排全重叠）
12. **mock 图标必须显示**（修复 1158）+ 有 mock 标识 + 引脚在框外侧
13. **并联电容先短网连接再连出去**
14. **芯片边缘电线要避让**（贴边缘走会被误检测或漏检测）
15. **元件间不重叠**（J8/R118、I18/I15 等）

## 12. 关键设计决策（完整记录，含裁决修正）

1. **SIG_NAME PAINT 裁决修正（重要）**：实读 04p4 golden page9.csa——SIG_NAME LASTPIN 块（FORCEPROP 2/3）**本就带 PAINT MONO + DISPLAY INVISIBLE**（L365 CAPACITOR / L12 GND_POWER）；无 PAINT 的是 $PN 块（L63-71）。此前"PAINT 是 SPCOCN-543 根因"判断系误读。**SPCOCN-543 真实根因 = 坐标未命中 symbol.css + 旋转组合**，由方案 B/C/D 处理。SIG_NAME PAINT 恢复 golden 一致（一期 QA Round2 裁决）
2. **mock 图标 CDS_LIB temp_lib**：mock 实例 `CDS_LIB temp_lib`（placeholder 仍 hdl_lib）+ OutputManager.write_cdslib 补 `DEFINE temp_lib temp_lib`（P1-2 修复；相对路径无 ./）
3. **Config.load_from_file 顶层子节合并**：修复 12 个子节（text_layout/overlap/power_ic/aesthetic/report/placeholder/ioport/mirror/gnd_distribution/temp_lib/wire_simplify/pin_audit）静默失效 bug（默认值掩盖）

5. **GND 聚类贪心最近邻而非 KMeans**：引脚数少（页均 <100），O(n²) 足够；KMeans 需 sklearn 依赖；cluster_radius=2000 用户 D4"先试不行反馈"；0=关闭聚类回退每芯片 1 个

7. **非均匀轨道**：元件 bbox 边坐标优先（SKiDL create_routing_tracks 思想），未命中回退均匀车道；`nonuniform_tracks` 默认关
8. **短网先布**：负号键等效升序（SKiDL rank_net）；`net_order` 默认 long_first（保持现状）；实测排序改变路径不改变段数（5031 vs 5034）——美观差异需 Cadence 目视

10. **悬空引脚直接悬空**：保留 LASTPIN 不画 WIRE；pin_audit 报告 [HANGING] 待 Allegro 布线
11. **mock 图标 cell 名 `<REFDES>_PH` 大写**：用户 D8（保留 _PH 后缀 + MOCK 标注）；temp_lib 不提交 git（D9）
12. **M3 腾挪只移 GND/标签**：芯片本体不动（D10，电气安全）；SKiDL α 调度属远期
13. **标注中英双标**：`MOCK/模拟图标` 字号 24（D11）；用 symbol.css P 指令（若实测不渲染改 X/T 指令，一行改动）
14. **审计基于 DesignConnectivity 模型**：raw EDIF pin_connections 未注入 → 100% 误报（数据源铁律）
15. **LASTPIN 内联各 FORCEADD 块**：集中文件尾会挂到 IOPORT 被删（SPCOCN-543）
16. **所有新功能独立模块+配置开关默认关**：用户强制，可回退（唯一例外：placeholder.enabled=true 后端默认生效）
